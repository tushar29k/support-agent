A support-ticket agent that may only say what the knowledge base says — and may only move money after a human approves it. Pick a sample ticket (or write your own) and watch retrieval, the draft, the approval gate and the tool calls stream in.

HOW IT WORKS

1 · Retrieve

Hybrid search over the policy KB: BM25 for exact terms, a dense-style scorer for paraphrases. Both scores shown per doc.

2 · Draft, grounded

The reply is assembled only from retrieved policy text, with citations. No doc, no claim — the agent escalates instead of improvising.

3 · Approval gate

Refunds are destructive. The run pauses and waits for a human yes/no — try denying one and watch the trace.

4 · Act + trace

Approved actions execute through MCP-style tools and land in the action store below, so every side effect is checkable.
